## Objetivo e Nome
Locadora de Carro -> Alugar automoveis para o publico
Nome -> Faster and Furious Rent Car

## Caso de uso
- Cadastro do veiculo
- Cadastro condutor
- Processo de aluguel e devolução

 
Cadastro do veiculo: Usuário cadastra o veículo usando Marca, Ano, Modelo, cor e placa

Cadastro do condutor: Usuário cadastra o condutor usando Nome, Data, Nascimento, CNH, CPF e Genero.

Processo de aluguel: Usuários relaciona veiculo ao condutor, data de aluguel, data de devolução, quantidade combustível saida e quantidade de combustivel entrada

# Requisitos técnicos

- Benckend em NodeJS + Express
- Frontend em React e vite. (Feito com  IA)
